### Some Github Projects
- [MACSE](https://github.com/ranwez/MACSE_V2_PIPELINES) — Frame-aware alignment of coding sequences 
- [SeqTUI](https://github.com/ranwez-search/SeqTUI) — Terminal-based sequence viewer and toolkit (vibe-coded)
- [GeCKO](https://github.com/GE2POP/GeCKO) - workflows for genotyping complex genomes using target enrichment capture
- [LRR profile](https://github.com/ranwez/LRRprofiler) - detect and annotate LRR (Leucine-Rich Repeat) containing plant receptors
- [Genetic Map Comparator](https://github.com/holtzy/GenMap-Comparator) - R Shiny application made to compare genetic maps
